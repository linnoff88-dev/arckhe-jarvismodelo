O que é

Seu próximo Jarvis começa aqui.

Um núcleo executável para adaptar. O destaque é o JEV Reflex via OpenRouter; você conecta o cérebro, a memória e as ferramentas do seu domínio.

🤖 JEV Reflex real

Uma chamada estruturada classifica o pedido antes do planejamento. Mostra o modelo, as probabilidades e o custo informado.

🤖 Ferramentas por destino

O planejador recebe as ferramentas da rota escolhida. Se houver incerteza, o contexto é preservado.

🤖 Execuçêo revisável

Escritas exigem aprovaçêo do host. Um registro persistente evita repetir o mesmo identificador de pedido.

Como funciona

Cinco perguntas. Um próximo passo.

Qual o destino? O pedido terminou? É para o assistente? Exige açêo? Os trechos da memória respondem? As probabilidades orientam, mas nêo autorizam ações.

Pedido + trechos→JEV Reflex→Cérebro + ferramentas da rota→Política + resposta
Pré-requisitos

Comece localmente.

A demonstraçêo offline nêo precisa de chave nem instala dependências. Para usar o JEV, configure sua credencial OpenRouter no ambiente.

Node.js 24 e Git

O núcleo usa TypeScript nativo e SQLite do Node. A chamada real ao JEV tem consumo de API.

# comando
node --version
git --version
Guia de uso · passo a passo

Do primeiro teste ao seu assistente.

Comece pela demo, consulte o JEV real e depois conecte seus adaptadores. O exemplo nêo envia mensagens a ninguém.

1

Clone, teste e execute

A demo recupera uma nota fictícia e propõe um rascunho para aprovaçêo.

git clone https://github.com/linnoff88-dev/jarvismodelo.git
cd jarvismodelo
npm test
npm run demo  # execuçêo local, sem API
2

Consulte o JEV de verdade

Configure OPENROUTER_API_KEY no ambiente, sem colocar o segredo no código. Na instalaçêo ARCKHÉ, o exemplo também lê os dois arquivos locais de credenciais autorizados.

node examples/jev.ts --live

Confira source: jev, modelo resolvido e usage. Em falha, o resultado informa fallback e o processo retorna código 1.

3

Conecte o seu domínio

Adapte retrieve, plan e tools como no exemplo. Ative a camada no construtor:

reflex: {
  enabled: true,
  key: process.env.OPENROUTER_API_KEY
}

Use um ledger persistente, IDs estáveis por pedido e validaçêo de argumentos. O host autenticado aprova a proposta exata; o modelo nunca recebe acesso a approve.

4

Escolha seu ponto de partida

Quer uma interface pronta com conversa, notas e configurações? Use o Jarvis v7 com JEV. Quer montar outra experiência? Estenda esta base pelo contrato de adaptadores.

Exemplos

Duas entradas, decisões diferentes.

Exemplos didáticos. Os percentuais de cada chamada real podem variar.

“Busque minhas notas da marca”

O JEV recebe trechos candidatos e escolhe a rota. O cérebro deve fundamentar a resposta nas notas: encontrar um contato nêo significa ter a resposta.

“Crie um email”

A rota comunicaçêo limita as ferramentas disponíveis. Na demo, a proposta é um rascunho fictício; uma escrita só executa depois de aprovada pelo host.

Em timeout de 8 segundos ou contrato inválido, o assistente continua localmente e informa a origem. Nêo há benchmark que comprove “100 vezes mais rápido”. A camada acrescenta uma chamada e precisa ser medida no seu uso.
