Qué es

Tu próximo Jarvis comienza aquí.

Un núcleo ejecutable para adaptar. Lo más destacado es JEV Reflex vía OpenRouter; conectas el cerebro, la memoria y las herramientas de tu dominio.

🤖 JEV Reflex real

Una llamada estructurada clasifica la solicitud antes de planificar. Muestra el modelo, las probabilidades y el costo informado.

🤖 Herramientas según el destino

El planificador recibe las herramientas de la ruta elegida. Si hay incertidumbre, se conserva el contexto.

🤖 Ejecución revisable

Las escrituras requieren la aprobación del host. Un registro persistente evita repetir el mismo identificador de solicitud.

Cómo funciona

Cinco preguntas. Un siguiente paso.

¿Cuál es el destino? ¿La solicitud terminó? ¿Es para el asistente? ¿Requiere una acción? ¿Los fragmentos de la memoria responden? Las probabilidades orientan, pero no autorizan acciones.

Solicitud + fragmentos→JEV Reflex→Cerebro + herramientas de la ruta→Política + respuesta
Requisitos previos

Empieza localmente.

La demostración offline no necesita una clave ni instala dependencias. Para usar JEV, configura tu credencial de OpenRouter en el entorno.

Node.js 24 y Git

El núcleo usa TypeScript nativo y SQLite de Node. La llamada real a JEV consume API.

# comando
node --version
git --version
Guía de uso · paso a paso

Desde la primera prueba hasta tu asistente.

Empieza con la demo, consulta el JEV real y después conecta tus adaptadores. El ejemplo no envía mensajes a nadie.

1

Clona, prueba y ejecuta

La demo recupera una nota ficticia y propone un borrador para su aprobación.

git clone https://github.com/inematds/jarvismodelo.git
cd jarvismodelo
npm test
npm run demo  # ejecución local, sin API
2

Consulta el JEV real

Configura OPENROUTER_API_KEY en el entorno, sin incluir el secreto en el código. En la instalación de INEMA, el ejemplo también lee los dos archivos locales de credenciales autorizados.

node examples/jev.ts --live

Comprueba source: jev, modelo resuelto y usage. Si falla, el resultado informa el fallback y el proceso devuelve el código 1.

3

Conecta tu dominio

Adapta retrieve, plan y tools como en el ejemplo. Activa la capa en el constructor:

reflex: {
  enabled: true,
  key: process.env.OPENROUTER_API_KEY
}

Usa un ledger persistente, IDs estables por solicitud y validación de argumentos. El host autenticado aprueba la propuesta exacta; el modelo nunca recibe acceso a approve.

4

Elige tu punto de partida

¿Quieres una interfaz lista con conversación, notas y configuración? Usa el Jarvis v7 con JEV. ¿Quieres crear otra experiencia? Amplía esta base con contrato de adaptadores.

Ejemplos

Dos entradas, distintas decisiones.

Ejemplos didácticos. Los porcentajes de cada llamada real pueden variar.

“Busca mis notas de marca”

JEV recibe fragmentos candidatos y elige la ruta. El cerebro debe fundamentar la respuesta en las notas: encontrar un contacto no significa tener la respuesta.

“Crea un email”

La ruta de comunicación limita las herramientas disponibles. En la demo, la propuesta es un borrador ficticio; la escritura solo se ejecuta después de que el host la apruebe.

Si se agotan los 8 segundos de espera o el contrato no es válido, el asistente continúa localmente e informa el origen. No hay ningún benchmark que demuestre “100 veces más rápido”. La capa agrega una llamada y debes medirla en tu uso.
